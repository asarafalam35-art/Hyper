# Hyper Social App

Instagram-style Flutter starter UI.

## Included
- Login screen
- Home feed
- Like button
- Comments button
- Create-post placeholder
- Search
- Profile
- Bottom navigation
- Dark theme

## Run
1. Install Flutter.
2. Run `flutter pub get`.
3. Run `flutter run`.

This starter is UI-only. Firebase authentication, storage, real posts, follows, chat, and notifications can be connected next.
